# ADR-005: Server-Sent Events (SSE) Proxy Routes for AI Assistant Tools

## Status
Approved

## Context
The AI developer tools (`ComponentGenerator`, `AccessibilityChecker`, `ThemeBuilder`) require streaming LLM responses token-by-token without exposing API secret keys to client browsers.

## Decision
We implemented Next.js API proxy endpoints (`/api/ai/generate-component`, `/api/ai/check-accessibility`, `/api/ai/build-theme`) utilizing **Server-Sent Events (SSE)** (`text/event-stream`).

Key safeguards:
1. **Zod Input Schema Validation**: Rejects empty or oversized payloads before querying APIs.
2. **IP Rate Limiting**: In-memory window limiting (max 20 requests per hour per IP).
3. **Interactive Fallbacks**: Built-in mock streams ensure tools remain functional during local development when no API key is provided.

## Consequences
### Positive
- Unidirectional SSE streams reduce perceived latency compared to full payload waits.
- Secure server-side API key management.
- Zero client-side API key exposure.

### Negative
- Requires serverless environments that support response streaming (configured with `X-Accel-Buffering: no`).
